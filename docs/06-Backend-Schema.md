# Backend Schema Document
## AI Recruiter Agent — Conversational Agentic Hiring Assistant

**Version:** 2.0 (Revised per updated workflow)
**Date:** July 15, 2026
**Database:** PostgreSQL (with `pgvector` extension)

---

## 1. Entity Relationship Overview

```
owners ──< requisitions ──< forms ──< platform_postings
                │
                └──< candidates ──< applications
                                      │
                                      ├──< resumes ──< resume_scores
                                      ├──< consents
                                      ├──< notifications (email/whatsapp)
                                      ├──< interview_invites
                                      ├──< meetings ──< interview_sessions ──< transcripts
                                      ├──< scorecards
                                      ├──< decisions
                                      └──< audit_log
```

## 2. Table Definitions

### 2.1 `owners` (the single recruiter/account holder)
```sql
CREATE TABLE owners (
    owner_id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    full_name        VARCHAR(255) NOT NULL,
    email            VARCHAR(255) UNIQUE NOT NULL,
    phone            VARCHAR(30),
    connected_platforms JSONB,         -- {"linkedin":"manual","naukri":"manual","internshala":"manual","zoom":"api","whatsapp":"api"}
    default_response_threshold INT DEFAULT 5,
    default_languages  JSONB DEFAULT '["en","hi","mr"]',
    created_at       TIMESTAMPTZ DEFAULT now(),
    is_active        BOOLEAN DEFAULT true
);
```

### 2.2 `requisitions`
```sql
CREATE TABLE requisitions (
    requisition_id      UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    owner_id            UUID REFERENCES owners(owner_id),
    raw_brief_text      TEXT NOT NULL,          -- the Owner's original natural-language input
    role_title          VARCHAR(255) NOT NULL,
    quantity            INT NOT NULL,
    work_mode           VARCHAR(20) CHECK (work_mode IN ('onsite','remote','hybrid')),
    duration            VARCHAR(100),
    compensation        VARCHAR(100),
    required_skills     JSONB,
    eligibility_rules   JSONB,
    response_threshold  INT DEFAULT 5,
    interview_time_limit_minutes INT DEFAULT 30,
    etiquette_note_text TEXT,
    status              VARCHAR(30) DEFAULT 'draft' CHECK (status IN ('draft','form_approved','active','threshold_reached','closed')),
    created_at          TIMESTAMPTZ DEFAULT now()
);
```

### 2.3 `forms`
```sql
CREATE TABLE forms (
    form_id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    requisition_id   UUID REFERENCES requisitions(requisition_id),
    form_schema      JSONB NOT NULL,          -- field definitions generated by Form Builder Agent
    owner_approved   BOOLEAN DEFAULT false,
    approved_at      TIMESTAMPTZ,
    hosted_url       TEXT,
    created_at       TIMESTAMPTZ DEFAULT now()
);
```

### 2.4 `platform_postings`
```sql
CREATE TABLE platform_postings (
    posting_id       UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    form_id          UUID REFERENCES forms(form_id),
    platform         VARCHAR(50) NOT NULL,    -- 'linkedin','naukri','internshala','career_page', etc.
    posting_mode     VARCHAR(20) CHECK (posting_mode IN ('api_auto','owner_manual')),
    platform_post_id VARCHAR(255),            -- if posted via API
    owner_confirmed_at TIMESTAMPTZ,           -- if posted manually by Owner
    posted_at        TIMESTAMPTZ,
    status           VARCHAR(30) DEFAULT 'pending' CHECK (status IN ('pending','live','expired','removed'))
);
```

### 2.5 `candidates`
```sql
CREATE TABLE candidates (
    candidate_id     UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    full_name        VARCHAR(255) NOT NULL,
    email            VARCHAR(255) NOT NULL,
    phone            VARCHAR(30),
    email_hash       VARCHAR(64) GENERATED ALWAYS AS (encode(digest(lower(email),'sha256'),'hex')) STORED,
    preferred_language VARCHAR(10) CHECK (preferred_language IN ('en','hi','mr')),
    source_platform  VARCHAR(50),
    created_at       TIMESTAMPTZ DEFAULT now(),
    UNIQUE (email_hash)
);
CREATE INDEX idx_candidates_email_hash ON candidates(email_hash);
```

### 2.6 `applications`
```sql
CREATE TABLE applications (
    application_id   UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    candidate_id     UUID REFERENCES candidates(candidate_id),
    requisition_id   UUID REFERENCES requisitions(requisition_id),
    form_id          UUID REFERENCES forms(form_id),
    applied_at       TIMESTAMPTZ DEFAULT now(),
    current_stage    VARCHAR(50) DEFAULT 'applied' CHECK (current_stage IN (
                        'applied','invited','interview_scheduled','interviewed',
                        'under_review','shortlisted','rejected','hold')),
    updated_at       TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX idx_applications_requisition ON applications(requisition_id);
CREATE INDEX idx_applications_stage ON applications(current_stage);
```

### 2.7 `consents`
```sql
CREATE TABLE consents (
    consent_id       UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    candidate_id     UUID REFERENCES candidates(candidate_id),
    consent_type     VARCHAR(50) NOT NULL,   -- 'data_processing','ai_screening','whatsapp_messages','ai_interview_recording'
    granted          BOOLEAN NOT NULL,
    granted_at       TIMESTAMPTZ,
    revoked_at       TIMESTAMPTZ,
    UNIQUE (candidate_id, consent_type)
);
```

### 2.8 `resumes` / `resume_scores`
```sql
CREATE TABLE resumes (
    resume_id        UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    application_id   UUID REFERENCES applications(application_id),
    file_url         TEXT NOT NULL,
    raw_text         TEXT,
    embedding        VECTOR(1536),
    parsed_fields    JSONB,
    parsed_at        TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE resume_scores (
    score_id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    application_id   UUID REFERENCES applications(application_id),
    skill_match_pct  NUMERIC(5,2),
    final_score      NUMERIC(5,2),
    rubric_breakdown JSONB,
    scored_at        TIMESTAMPTZ DEFAULT now()
);
```

### 2.9 `notifications` (Email + WhatsApp)
```sql
CREATE TABLE notifications (
    notification_id  UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    candidate_id     UUID REFERENCES candidates(candidate_id),
    application_id   UUID REFERENCES applications(application_id),
    channel          VARCHAR(20) CHECK (channel IN ('email','whatsapp')),
    template_name    VARCHAR(100),
    language         VARCHAR(10) CHECK (language IN ('en','hi','mr')),
    content_snapshot TEXT,
    sent_at          TIMESTAMPTZ,
    status           VARCHAR(20) CHECK (status IN ('queued','sent','delivered','failed')),
    consent_verified BOOLEAN DEFAULT false
);
```

### 2.10 `interview_invites`
```sql
CREATE TABLE interview_invites (
    invite_id        UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    application_id   UUID REFERENCES applications(application_id),
    proposed_date     DATE,
    proposed_time     TIME,
    time_limit_minutes INT,
    etiquette_note_sent BOOLEAN DEFAULT false,
    candidate_confirmed BOOLEAN DEFAULT false,
    confirmed_at      TIMESTAMPTZ,
    reschedule_requested BOOLEAN DEFAULT false
);
```

### 2.11 `meetings`
```sql
CREATE TABLE meetings (
    meeting_id       UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    application_id   UUID REFERENCES applications(application_id),
    platform         VARCHAR(20) CHECK (platform IN ('zoom','google_meet')),
    meeting_url      TEXT NOT NULL,
    scheduled_start  TIMESTAMPTZ,
    created_at       TIMESTAMPTZ DEFAULT now(),
    status           VARCHAR(30) DEFAULT 'created' CHECK (status IN ('created','link_sent','in_progress','completed','failed'))
);
```

### 2.12 `interview_sessions`
```sql
CREATE TABLE interview_sessions (
    session_id       UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    meeting_id       UUID REFERENCES meetings(meeting_id),
    bot_provider     VARCHAR(50),            -- 'recall_ai','meetstream_ai'
    disclosure_confirmed BOOLEAN DEFAULT false,  -- AI-interviewer + recording disclosure given
    primary_language  VARCHAR(10) CHECK (primary_language IN ('en','hi','mr')),
    started_at       TIMESTAMPTZ,
    completed_at     TIMESTAMPTZ,
    status           VARCHAR(30) DEFAULT 'scheduled' CHECK (status IN (
                        'scheduled','in_progress','completed','failed','rescheduled')),
    recording_url    TEXT
);
```

### 2.13 `transcripts`
```sql
CREATE TABLE transcripts (
    transcript_id    UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    session_id       UUID REFERENCES interview_sessions(session_id),
    turn_index       INT NOT NULL,
    speaker          VARCHAR(20) CHECK (speaker IN ('agent','candidate')),
    language_detected VARCHAR(10),
    message_text     TEXT,
    timestamp        TIMESTAMPTZ DEFAULT now()
);
```

### 2.14 `scorecards`
```sql
CREATE TABLE scorecards (
    scorecard_id     UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    application_id   UUID REFERENCES applications(application_id),
    session_id       UUID REFERENCES interview_sessions(session_id),
    communication_score   NUMERIC(3,1),
    technical_score       NUMERIC(3,1),
    problem_solving_score NUMERIC(3,1),
    role_fit_score        NUMERIC(3,1),
    justification_text    JSONB,
    generated_at           TIMESTAMPTZ DEFAULT now(),
    model_version          VARCHAR(50)
);
```

### 2.15 `decisions` (human-in-the-loop record)
```sql
CREATE TABLE decisions (
    decision_id      UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    application_id   UUID REFERENCES applications(application_id),
    decided_by        UUID REFERENCES owners(owner_id),
    final_decision    VARCHAR(30) CHECK (final_decision IN ('shortlisted','rejected','hold')),
    override_note     TEXT,
    decided_at        TIMESTAMPTZ DEFAULT now()
);
```

### 2.16 `audit_log` (immutable, append-only)
```sql
CREATE TABLE audit_log (
    log_id           BIGSERIAL PRIMARY KEY,
    entity_type      VARCHAR(50) NOT NULL,
    entity_id        UUID NOT NULL,
    action           VARCHAR(100) NOT NULL,  -- 'form_generated','posted','message_sent','meeting_created','interview_completed','decision_made'
    actor_type       VARCHAR(20) CHECK (actor_type IN ('system','owner')),
    actor_id         UUID,
    details          JSONB,
    prev_hash        VARCHAR(64),
    record_hash      VARCHAR(64),
    created_at       TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX idx_audit_entity ON audit_log(entity_type, entity_id);
```

## 3. Key Design Notes

- **Single-Owner scoping:** all requisitions and decisions trace back to one `owners` row per account — simpler than the multi-recruiter enterprise schema from the original design; a `team_id` layer can be added later for Phase 2 multi-recruiter support without breaking this structure.
- **`posting_mode` field on `platform_postings`** explicitly distinguishes API-automated posting from Owner-manual posting — this keeps the ToS-risk boundary visible in the data model itself, not just in process documentation.
- **`consents` table includes `ai_interview_recording`** as its own consent type, separate from general data processing — reflecting the extra disclosure needed specifically for the live AI-conducted interview.
- **`interview_sessions.disclosure_confirmed`** is a hard gate: the interview logic should not proceed past the opening disclosure step until this flag is set true, enforced at the application layer.
- **`transcripts.language_detected`** per turn supports analyzing code-switching patterns and auditing multilingual accuracy over time.
- **`decisions` table enforces human accountability** — every final status requires a `decided_by` Owner and, for any AI-vs-human disagreement, a mandatory note.
- **No protected-attribute fields** are stored in any scoring-relevant table; if collected at all for voluntary reporting, they belong in a separate, access-restricted table never joined into scoring queries.

## 4. Suggested Indexes for Performance

```sql
CREATE INDEX idx_requisitions_owner ON requisitions(owner_id);
CREATE INDEX idx_notifications_candidate ON notifications(candidate_id);
CREATE INDEX idx_transcripts_session ON transcripts(session_id);
CREATE INDEX idx_resumes_embedding ON resumes USING ivfflat (embedding vector_cosine_ops);
```
